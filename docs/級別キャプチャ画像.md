# 級別キャプチャ画像ルール

級別SEO LP（`/1kyu/` など）の技能セクションに載せるアプリ画面キャプチャの置き方・命名・表示仕様です。  
画像を置くだけでコード変更なしで差し替わります（`includes/grade-data.php` の `grade_screen_url()`）。

---

## 1. 置き場所

```
assets/images/grade/{slug}/{key}.{ext}
```

| 項目 | ルール |
|------|--------|
| `{slug}` | URLスラッグと同じ（下表） |
| `{key}` | 技能・大問ごとのキー（下表「キー一覧」） |
| `{ext}` | **`webp` / `jpg` / `png`**。探索優先は **webp → jpg → png** |

方針: 可能なら webp。当面は jpg や png でも問題なし（あとから同名の webp を置けば自動で webp 側が使われます）。

各級フォルダはあらかじめ用意済みです（中身は `.gitkeep` のみでも可）。

| slug | 級 |
|------|-----|
| `1kyu` | 英検1級 |
| `jun1kyu` | 英検準1級 |
| `2kyu` | 英検2級 |
| `jun2kyu-plus` | 英検準2級プラス |
| `jun2kyu` | 英検準2級 |
| `3kyu` | 英検3級 |
| `4kyu` | 英検4級 |
| `5kyu` | 英検5級 |

**例**

```
assets/images/grade/1kyu/word-1.jpg
assets/images/grade/2kyu/reading-2.webp
assets/images/grade/jun2kyu/speaking-1.png
assets/images/grade/jun2kyu/writing-3.webp
```

---

## 2. フォールバック（画像がないとき）

`grade_screen_url($slug, $key)` の解決順:

1. `assets/images/grade/{slug}/{key}.{ext}` があればそれ
2. なければ共通アプリ画面 `assets/images/app-screen-{skill}.{ext}`  
   （`word-1` → `app-screen-word` など。キーと skill の対応は `grade-data.php` 内 `$fallbackMap`）
3. それもなければ `assets/images/app-screen-placeholder.svg`

級別画像は揃うまで共通キャプチャ／プレースホルダーで表示されます。**1枚ずつ置いていけばOK**です。

---

## 3. キー一覧（ファイル名の本体）

キーは `includes/grade-data.php` の各級データと一致させます。  
級によって大問数が違うため、**その級に定義されているキーだけ**用意すれば十分です。

### 単語（全級・常に3枚）

| キー | 想定内容（キャプション） |
|------|--------------------------|
| `word-1` | 4択で意味を選ぶ |
| `word-2` | 正誤と解説がその場で表示 |
| `word-3` | 履歴で弱点だけ復習 |

### リーディング（大問ごと）

| キー | 使う級の目安 |
|------|----------------|
| `reading-1` | 全級 |
| `reading-2` | 全級 |
| `reading-3` | 全級（5級まで） |
| `reading-4` | 準2級・4級 など4大問の級のみ |

### リスニング（大問ごと）

| キー | 使う級の目安 |
|------|----------------|
| `listening-1` | 全級 |
| `listening-2` | 全級 |
| `listening-3` | 1級・準1・準2・3・4・5級 など |
| `listening-4` | 1級のみ（インタビュー等） |

### ライティング（3級以上。4・5級はセクション自体なし）

| キー | 想定内容 |
|------|----------|
| `writing-1` | 要約 or Eメール（級による） |
| `writing-2` | 英作文（意見論述） |
| `writing-3` | AIリアルタイム添削画面 |

### スピーキング（**準2級のみ**）

| キー | 想定内容 |
|------|----------|
| `speaking-1` | イラストの質問 |
| `speaking-2` | トピックの質問 |
| `speaking-3` | 意見の質問 |

## 4. 表示仕様（撮影・書き出しの目安）

CSS（`.grade-capture-card__frame` / `__img`）に合わせた推奨です。

| 項目 | 推奨 |
|------|------|
| 向き | **横長（4:3）** |
| アスペクト比 | **4:3**（枠の `aspect-ratio` と同じ） |
| HTML上のサイズヒント | `width="640"` `height="480"`（比率の目安） |
| トリミング | `object-fit: cover` + `object-position: top center` → **画面上部（ヘッダー・設問側）を優先**して写す |
| 形式 | **webp（推奨）** → jpg → png |
| 解像度 | 短辺 720px 前後以上推奨（Retina向け）。極端に重い原寸は避ける |

枠は角丸＋薄いボーダー付き。キャプチャ側に余計な余白・デバイスベゼルを大きく入れる必要はありません（アプリUIをフレームいっぱいに）。

---

## 5. セクションごとの並び

| セクション | グリッド | 備考 |
|------------|----------|------|
| 単語 | 常に3列相当（`grade-capture-grid--3`） | キャプションのみ（figcaption） |
| リーディング／リスニング／ライティング／スピーキング | 大問数に応じて 2〜4 列 | タイトル＋説明文付き |

大問数の定義は級ごとに `grade-data.php` の `parts` / `images` を編集します。画像キーを増やす場合は、データ側の `key` / `image` も合わせて追加してください。

---

## 6. 差し替え手順（チェックリスト）

1. 該当級フォルダに `{key}.png` または `{key}.jpg` を置く（余裕があれば `{key}.webp`）  
2. ブラウザで `/1kyu/` など該当URLをハードリロードして確認  
3. 意図した画面か・上部が切れていないか（`object-position: top`）を見る  
4. Git に画像を追加してデプロイ  
5. あとから webp を同名で追加すれば、jpg / png より優先して表示される（元ファイルは残しても削除しても可）

コードの編集は不要です。キー名を変えたい／大問を増やす場合のみ `includes/grade-data.php` を更新します。
