# AiKen ASOレポート（2026-11-20）

App Store の iOS アプリ「AiKen｜英検単語・4技能対策」について、アプリのダウンロードを増やすために何を直すかを整理した。Google Play は公開（11/2）から日が浅いので、今回は扱わない。

まず結論。

1. **詰まっているのは、検索結果からプロダクトページへ進むところ。** インプレッション6,410に対してページ閲覧は445（約7%）。一方で、ページを見た人のうち約34%（152件）がダウンロードしている。手を入れる順は、検索結果に出る部分（名前、サブタイトル、アイコン、スクリーンショットの1〜3枚目）が先で、説明文は後。
2. **級の名前で検索されても引っかからない。** 名前とサブタイトルに入っている級は「5級〜1級」だけ。Web検索の需要は「英検3級 アプリ」「英検準1級 アプリ」のように級を付けたものが多い。級の名前と「面接」「リスニング」はキーワード欄に入れる。
3. **第3回（申込締切 12/14、一次 2027-01-24）の前に、宣伝テキストとアプリ内イベントを使う。** どちらも検索結果やページで目に入る場所で、宣伝テキストは審査なしで差し替えられる。
4. **流入元を分けて見られるようにする。** LP からストアへのリンクにキャンペーン用のパラメータ（`pt` / `ct`）を付け、App Store の検索から来た人と aiken.life から来た人を分けて数える。

## 3. キーワード

### 名前とサブタイトルで拾えている語

AiKen、英検、単語、4技能、対策、5級、1級、文法、AI、添削、英作文。

App Store は、名前・サブタイトル・キーワード欄の語を組み合わせて検索に当てる。同じ語を2か所に入れても効果は増えない。キーワード欄では、名前とサブタイトルにない語だけを使う。

### Web 検索から見た需要（11/17・11/19のSEOレポートより）

- 級の指定なし：「英検 アプリ」「英検対策 アプリ」が最大。名前で拾えている。
- 級つき：「英検3級 アプリ」「英検準1級 アプリ」「英検準二級アプリ」「英検 4級 アプリ 無料」。**名前の「5級〜1級」では3級・準2級・準1級にほぼ当たらない。**
- 面接：「英検3級 二次試験 ai」「英検 面接対策アプリ」「英検準2級 二次試験 対策 アプリ」。競合も面接を名前に入れている。
- ライティング：「英検2級ライティング添削」。サブタイトルの「AI添削・英作文」で拾えている。
- 過去問：「英検 5級 過去 問 アプリ」。AiKen は過去問ではないので狙わない（LPと同じ方針）。

### キーワード欄の案（100文字以内、半角カンマ区切り、スペースなし）

```
3級,準2級,2級,準1級,4級,プラス,面接,二次試験,スピーキング,リスニング,リーディング,ライティング,要約,英単語,問題集,勉強,英語,採点,発音,中学生
```

82文字。外した語とその理由。

- 名前・サブタイトルと重なる語（英検、単語、対策、文法、AI、添削、英作文、5級、1級）：すでに拾えている。
- 過去問：中身と合わない。
- 他社のアプリ名、「英検®」：他社名は審査で外される。「英検」は名前に入っている。

いまのキーワード欄の中身は、このリポジトリにも eiken-app にも記録が無い。App Store Connect で今の値を確かめ、上の案と差し替える前に、この文書へ書き写しておく。

### 名前とサブタイトルの案

| | 今 | 案 |
|--|----|----|
| 名前 | AiKen｜英検単語・4技能対策 | AiKen｜英検対策 単語・面接・4技能（20文字） |
| サブタイトル | 5級〜1級 文法・AI添削・英作文 | 変えない |

名前に「面接」を足し、「英検対策」を一続きにする。級の名前は名前に入れると長くなり、検索結果で読みにくくなるので、キーワード欄に回す。

名前を変えると、ブランド名で探す人への見え方も変わる。キーワード欄の差し替えを先にして、2週間ほど閲覧数とダウンロード数を見てから名前を変える。一度に複数を変えると、どれが効いたか分からない。

## 4. 施策

### A. 今週やること（App Store Connect、審査なしか軽い審査）

| 順 | 作業 | 理由 |
|----|------|------|
| 1 | 今のキーワード欄を書き写し、§3 の案に差し替える | 級つき・面接の検索にまだ当たっていない |
| 2 | 宣伝テキストを第3回向けにする。例：「第3回英検（一次 1月24日）に向けて。単語と文法は毎日無料、4技能は最初の5日間使い放題。」 | 審査なしで差し替えられる。申込締切 12/14 の前に出す |
| 3 | スクリーンショットの1〜3枚目に、級を選べること・AI採点の面接・AI添削を、短い文字で出す | 検索結果に出るのは最初の数枚。タップ率（6.9%）を上げる |
| 4 | [ストア公開.md](../ストア公開.md) の名前・サブタイトル・言語を今の値に直す | LP と FAQ はこの文書を正としているため |

### B. 12月にやること

- **アプリ内イベント**：「第3回 一次試験 直前対策」のようなイベントを 12/14 前後から 1/24 まで出す。検索結果とページにカードで出て、インプレッションが増える。
- **LP → ストアの計測**：`config.php` の `APP_STORE_URL` に `pt`（プロバイダトークン）と `ct`（キャンペーン名）を付ける。`ct` は LP の pid と同じ考え方で、`lp_top`、`lp_3kyu` などにする。App Store Connect の「キャンペーン」で、LP からのダウンロードを分けて数えられる。プロバイダトークンは App Store Connect の「キャンペーンリンクを生成」で確認する。
- **カスタムプロダクトページ**：級別LP（`/3kyu/` など）から、その級のスクリーンショットを先頭にしたページへ送る。キーワードとの紐づけもできる。閲覧が少ないうちは、3級と準1級の2つから始める（Web検索で需要が見えている級）。

### C. やらないこと（今期）

- **プロダクトページの最適化（A/Bテスト）**：閲覧が90日で445しかなく、結果が出るまで時間がかかりすぎる。カスタムプロダクトページとキーワードを先にやる。
- **説明文の書き直し**：ページに来た人の34%がダウンロードしている。説明文は詰まっている場所ではない。
- **カテゴリの変更**：教育のままにする。
- **評価の依頼の追加**：アプリにはすでに、良い結果のときと連続学習の節目に OS の評価シートを出す仕組みがある（`eiken-app/mobile/lib/store-review-prompt.ts`）。評価4件は、母数が小さいことの結果。
