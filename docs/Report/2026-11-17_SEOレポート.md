検索で伸ばすページと、そのページでやることを、Search Console と Analytics のランディングページから整理した。

結論から書く。次の四半期で手を入れる順番はこれ。

1. **トップ `/`** … 会員登録の本体。ヘッドクエリ「英検対策アプリ」「英検 アプリ」はまだ2〜3ページ目。
2. **準1級アプリ記事** `/blog/eiken-jun1kyu-app/` … すでに1ページ目なのに、タイトルがクリックを取れておらず、登録が0。
3. **3級スピーキング** `/3kyu/speaking/` と **3級トップ** `/3kyu/` … 順位は10〜13位、クリック率も登録率も良い。あと一段で増える。
4. **準1級トップ** `/jun1kyu/` … 滞在が長く、登録も付いている。アプリ記事と役割を分ける。

7. **アプリ比較記事** `/blog/eiken-apps/` … 「おすすめ」意図の受け皿。今は22位。

単語記事を増やして表示回数を追う段階ではない。登録が起きているページの順位と、すでに1ページ目にいるページのクリック率・登録導線を直す段階。

## 1. データの範囲と読み方

| データ | 期間 | 範囲 |
|--------|------|------|
| Search Console 日次・デバイス・国・ページ・クエリ | 2026-08-16 〜 2026-11-15（92日） | ウェブ検索 |
| Analytics ランディングページ | 2026-08-19 〜 2026-11-16 | すべてのユーザー |

会員登録は、ランディングページレポートの **イベント数** をCVとして読んだ。キーイベントと収益はページ判断に使っていない。キーイベント265件と収益980円がほぼすべて「（未設定）」に寄っており、この書き出しではページごとの有料化は見えない。

次の3点を前提にする。

- **クエリ一覧は先頭1,000件で、サイト全体の約25%（クリック197 / 784、表示7,627 / 25,172）しかカバーしない。** クエリの話は頭のクエリの話であり、取りこぼしたテールはページ側の数字で補う。
- **Analytics は全チャネル、Search Console は検索のみ。** セッション数と検索クリック数は突き合わせない。登録の起きやすさは Analytics、順位と表示は Search Console、と分けて読む。
- **イベント数は件数であり、ユニークな登録者数ではない。** ページ同士の比較には使える。ダッシュボードやログインにもイベントが付いているので、新規ユーザーが大半のページ（トップ、級ページ、ブログ）を獲得ページとして見る。
- **URL末尾の `#index_id` はクリック0のまま表示だけが分かれて出ている**（合計表示約7,440）。需要の判断には `#` なしの行を使う。単語記事の本体はクリック154・表示4,158・CTR 3.7%・順位8.6であり、アンカーを足した7,814表示ではない。

## 5. 伸ばすページと、そこでやること

優先度は「登録が起きているか」「アプリ意図のクエリか」「あと少しで1ページ目か、1ページ目なのにクリックされていないか」で付けた。数字は `#` なしのURL。

### 優先1. トップ `/`

| Search Console | Analytics |
|----------------|-----------|
| クリック123 / 表示2,805 / CTR 4.39% / 順位14.4 | セッション726 / 新規457 / 滞在148秒 / 登録97 |

ページ全体の平均順位は14位。ヘッドクエリに限ると「英検対策 アプリ」20.5位、「英検 アプリ」27.6位、「英検対策アプリ」24.0位。タイトルはすでに「英検対策アプリ」から始まっているので、文言の微修正より評価を渡すリンクが先。

やること。

- 級LPとアプリ記事のパンくずと本文から、トップへ「英検対策アプリ」のアンカーで戻す。今は記事が級の情報で完結し、ヘッドクエリの評価がトップに集まっていない。
- トップ内に、級別（5級・4級・3級・準2級・準2級プラス・2級・準1級・1級）のアプリ導線を見出し付きで置く。3級アプリ（CTR 10.6%）のような「級＋アプリ」の受け皿をトップにも持たせる。
- 「おすすめ」「勉強 アプリ」は比較記事（優先7）に任せ、トップからはその記事へ内部リンクする。トップ単体で比較クエリ全部を取りにいかない。
- Android公開（2026年11月）をタイトル近くの更新日と本文に残し、11月の伸びを鮮度として維持する。

同じ表示回数のまま順位が1ページ目の上位に入れば、クリックはおおむね倍が目安。表示回数自体も順位が上がると増える。四半期でいちばん大きいレバーはここ。

## 7. サイト共通で先にやること

個別ページと並行して、次の4つ。

**内部リンクの向きを固定する。**

ブログ（情報） → 級LPまたは技能LP（その級で練習する） → 会員登録。  
アプリ記事どうしの回遊で終わらせない。トップへ戻すアンカーは「英検対策アプリ」にそろえる。

**登録ブロックを1種類にする。**

「この級をアプリで続ける。5日間、カード登録の案内は料金ページに合わせる。」級名・技能名・リンク先だけ差し替える。入れる位置は、一覧記事なら目次の直後と中盤、アプリ記事なら比較表の直後、技能LPなら3級スピーキングと同じ位置。

**1ページ目でCTRが1%前後のページから手を入れる。**

対象は準1級アプリのクエリ「英検準一級 アプリ」、4級文法、5級文法、5級アプリ。順位が10位より悪いページのタイトル変更は、内部リンクのあと。

**計測を次のレポートまでに1段直す。**

- 登録イベントに、着地URL（または参照元ページ）が残るようにする。未設定の110件がどこの流入か分からないと、SEOの寄与をページに帰属できない。
- 収益とキーイベントは、ランディング別の判断に使わない。有料化を見るなら、登録とは別のイベントでページが付く状態にしてから次のレポートに載せる。
- `#index_id` のURLがSearch Consoleのページレポートに残っているか、来月もう一度見る。残っていても需要には足さない。
