## 1. 全記事のパンくず

SWELLは「ホーム」をパンくず配列の外に出す。配列の0番目は親カテゴリ（4級なら「英検対策」→ `/blog/category/eiken/`）なので、0番目を書き換えるとホームは残り、親カテゴリが消える。

先に、そのフィルターは削除する。消すと「英検対策」が戻る。

そのうえで2つ入れる。

1. 外観 → カスタマイズ → サイト全体設定 → パンくずリスト → 「ホームの文字列」を `英検対策アプリ` にする。ここで変わるのは文字だけ。
2. 子テーマの `functions.php` か Code Snippets に、ホームのURLだけを差し替えるコードを置く。親テーマは触らない。

```php
add_filter('home_url', function ($url, $path) {
    if ($path !== '/' && $path !== '') {
        return $url;
    }
    $trace = debug_backtrace(DEBUG_BACKTRACE_IGNORE_ARGS, 12);
    foreach ($trace as $frame) {
        $file = $frame['file'] ?? '';
        if (stripos($file, 'breadcrumb') !== false) {
            return 'https://aiken.life/';
        }
    }
    return $url;
}, 10, 2);
```

4級のカテゴリは、次の並びになる。

- 英検対策アプリ → `https://aiken.life/`
- 英検対策 → `/blog/category/eiken/`
- 英検4級

構造化データのパンくずに「ホーム」は入っていない。先頭が `https://aiken.life/` でなければ、同じ場所に次も足す。すでに先頭が `https://aiken.life/` なら足さない。

```php
add_filter('swell_json_ld', function ($data) {
    if (!is_array($data) || !isset($data['@graph']) || !is_array($data['@graph'])) {
        return $data;
    }
    foreach ($data['@graph'] as &$node) {
        if (($node['@type'] ?? '') !== 'BreadcrumbList' || empty($node['itemListElement'])) {
            continue;
        }
        $first = $node['itemListElement'][0]['item']['@id'] ?? '';
        if (untrailingslashit($first) === 'https://aiken.life') {
            continue;
        }
        array_unshift($node['itemListElement'], [
            '@type' => 'ListItem',
            'item' => [
                '@id' => 'https://aiken.life/',
                'name' => '英検対策アプリ',
            ],
        ]);
        $position = 1;
        foreach ($node['itemListElement'] as &$item) {
            $item['position'] = $position;
            $position++;
        }
        unset($item);
    }
    unset($node);
    return $data;
});
```
