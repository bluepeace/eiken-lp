```php
add_filter('home_url', function ($url, $path) {
```

4級のカテゴリは、次の並びになる。

画面のパンくずは3段でも、構造化データはURLのある段だけになる。SWELLはホームを配列の外に出し、今いるページはリンクがないのでJSON-LDから落とす。

`swell_json_ld` に渡る配列は、0番目から並ぶリストではない。キーが `WebSite` や `BreadcrumbList` の連想配列で、出力の直前に `@graph` へ並び替えられる。前のコードは `$data[0]` が無いと何もせず返していた。

今入っている `swell_json_ld` は消して、次に差し替える。`BreadcrumbList` の先頭が `https://aiken.life/` ならホームは足さない。末尾が今のページでなければ、記事またはカテゴリを足す。

```php
add_filter('swell_json_ld', function ($data) {
    if (!is_array($data) || !isset($data['BreadcrumbList']) || !is_array($data['BreadcrumbList'])) {
        return $data;
    }

    $items = isset($data['BreadcrumbList']['itemListElement']) && is_array($data['BreadcrumbList']['itemListElement'])
        ? $data['BreadcrumbList']['itemListElement']
        : [];
    $first = '';
    if (isset($items[0]['item'])) {
        $first = is_array($items[0]['item'])
            ? (string) ($items[0]['item']['@id'] ?? '')
            : (string) $items[0]['item'];
    }
    if (untrailingslashit($first) !== 'https://aiken.life') {
        array_unshift($items, [
            '@type' => 'ListItem',
            'item' => [
                '@id' => 'https://aiken.life/',
                'name' => '英検対策アプリ',
            ],
        ]);
    }

    $current_url = '';
    $current_name = '';
    if (is_singular()) {
        $current_url = (string) get_permalink();
        $current_name = wp_strip_all_tags(get_the_title());
    } elseif (is_category() || is_tag() || is_tax()) {
        $term = get_queried_object();
        if ($term instanceof WP_Term) {
            $link = get_term_link($term);
            if (!is_wp_error($link)) {
                $current_url = (string) $link;
                $current_name = $term->name;
            }
        }
    }
    $last_id = '';
    $last = $items ? $items[array_key_last($items)] : null;
    if (is_array($last) && isset($last['item'])) {
        $last_id = is_array($last['item'])
            ? (string) ($last['item']['@id'] ?? '')
            : (string) $last['item'];
    }
    if ($current_url !== '' && $current_name !== '' && untrailingslashit($last_id) !== untrailingslashit($current_url)) {
        $items[] = [
            '@type' => 'ListItem',
            'item' => [
                '@id' => $current_url,
                'name' => $current_name,
            ],
        ];
    }

    $position = 1;
    foreach ($items as &$item) {
        $item['position'] = $position;
        $position++;
    }
    unset($item);
    $data['BreadcrumbList']['itemListElement'] = $items;
    return $data;
});
```

プレスリリース記事なら、構造化データは次の3段になる。

- プレスリリース → `https://aiken.life/blog/category/press/`
