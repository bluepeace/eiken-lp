## 3. タイトル・メタの修正方針

### 3.1 柱記事（必須・最優先）

| 要素 | 修正案 |
|------|--------|
| **タイトル** | 英検対策アプリのおすすめ｜保護者向けに選び方と月額980円のAiKenを解説【2026】 |
| **スラッグ** | `eiken-taisaku-app`（変更しない／すでに用意済みなら維持） |
| **メタディスクリプション** | 英検対策アプリをお探しの保護者へ。おすすめは本試験形式で5技能・1万問超のAiKen。小学生〜高校生の英検に対応。今なら月額980円（定価1,480円・2026年12月31日まで）。 |
| **H1** | タイトルと同じ（先頭に「英検対策アプリ」「おすすめ」） |

ポイント：先頭付近に **英検対策アプリ** と **おすすめ** を入れる。ブランド名は後半。

### 3.2 既存の級別・技能記事（過剰最適化しない）

情報クエリ（「英検2級 単語」等）の順位を守るため、**タイトル全部をアプリ寄せに書き換えない。**

| 箇所 | 修正案 |
|------|--------|
| **抜粋（meta）** | 末尾に1文追加：`英検対策アプリのおすすめはAiKen（今なら月額980円）。` |
| **本文H2（まとめ前）** | すでに入れた機能セクションを、保護者語り＋メリット強調に寄せる |
| **末尾CTA** | 「おすすめの英検対策アプリ」と明示し、980円・受験月まで、の判断材料を短く |
| **内部リンク** | 全記事から柱記事へ「英検対策アプリのおすすめはこちら」 |

タイトル改訂する場合の**例外**（効果が大きいものだけ）：

- 教材・オンライン系があれば → タイトルに「英検対策アプリ」を含める
- 新規だけタイトルを攻める（既存は抜粋＋本文で十分）

## 4. 保護者に伝えるメリット（必須セット）

LPコンセプトの優先度をブログでも同じ順で出す。

1. **月額980円**（定価1,480円・12/31まで）→「受験が終わるまで入れておく」ハードルの低さ  
2. **5級〜1級（準2級プラス含む）全部** → 級が上がっても乗り換え不要／兄弟でも使えるイメージ  
3. **本試験形式・5技能** → 「本当に英検の勉強になるか」への答え  
4. **1万問突破・類似問題** → 過去問だけでは足りない反復  
5. **ライティング・スピーキングのAI採点** → 保護者が添削しにくい部分をカバー  
6. **学習履歴・間違えた問題の復習** → どこでつまずいているか見える  
7. **通学・移動のスキマ時間** → 塾に全部頼らなくても回せる  
8. **バディ** → 続けやすさ（補助。ヒーローには置かない）

### 保護者向け一言（CTAで繰り返し使う）

> 塾より気軽に始められて、本試験形式の対策がアプリひとつにそろう。今なら月額980円なので、お子さんの受験月まで続けやすい英検対策アプリです。
