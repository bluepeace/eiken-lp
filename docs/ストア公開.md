### 2.1.1 審査 3.1.2（Subscriptions / EULA）

自動更新サブスクがある場合、**商品ページに機能する EULA リンク**が必要。自社の「利用規約」URL だけでは、審査ボットが EULA と見なさないことがある。

| やり方 | 内容 |
|--------|------|
| **推奨（今回）** | 標準 Apple EULA を使う。説明文に上記 `Terms of Use (EULA)：https://www.apple.com/legal/internet-services/itunes/dev/stdeula/` を入れる。**新しいビルドは不要**。1.1.1 の説明を直して再提出する。 |
| 代替 | App Store Connect → App情報 → ライセンス契約 → **カスタム EULA** に自社規約全文を登録する。 |

再提出手順:

1. [App Store Connect](https://appstoreconnect.apple.com/) → AiKen → 却下された iOS 1.1.1
2. 日本語ロケールの **説明** を `app-store-jp-description.txt` の全文に差し替え（EULA 行を消さない）
3. プライバシーポリシー URL が `https://app.aiken.life/privacy` のままか確認
4. 保存 → **App Review に再提出**

言語表示（英語→日本語）はバイナリ側の修正なので、この 3.1.2 の再提出とは分けて、次バージョンで出す。

## 4. LP・FAQ を直すときの注意

現状の LP は Web アプリ前提の文言が残っています（例: 「ブラウザですぐはじめられる」「アプリのインストールは不要」）。ストア導線を出すときは次を揃える。

- CTA は Web 登録に加え、App Store（公開後は Google Play）へのリンクを用意する
- 料金・解約は **Web（Stripe）** と **ストア課金（Apple / Google）** で手順が違う
- 未成年のプレミアム契約は Web 案内を残す
- FAQ「このサイトとアプリの違い」は、Web アプリとネイティブアプリの両方を説明するようにする

定数を置く場合の候補: `config.php` に `APP_STORE_URL` / `PLAY_STORE_URL`（Android 公開まで空または未定義でも可）。
